# Модуль обновлений Meiyuren

## Источник

Только [https://github.com/Aspksa/Meiyuren](https://github.com/Aspksa/Meiyuren), ветка `main`. Последний коммит получается через GitHub REST API. Неизвестные репозитории, ветки и коммиты запрещены.

## Как работает

1. Пользователь нажимает на векторный значок круговых стрелок слева.
2. Локальный Node/Vite запрашивает HEAD `main` и список запусков GitHub Actions.
3. Кнопка установки включается, только если текущая папка — корень клона с origin на Aspksa/Meiyuren, ветка `main`, рабочее дерево чистое, версия отличается, а CI завершилась успешно для **точного** SHA.
4. Пользователь отдельно подтверждает установку.
5. Сервер повторно сверяет HEAD и CI, загружает строго `refs/heads/main`, проверяет SHA, происхождение и возможность fast-forward.
6. Сохраняется SHA предыдущей версии в `.meiyuren/last-update.json`, выполняется `git merge --ff-only`. Принудительные перезаписи при обновлении запрещены.
7. Приложение сообщает о необходимости перезапуска; `npm install` при изменении зависимостей выполняется отдельно.

## Откат

Кнопка доступна лишь после успешного обновления, когда HEAD равен установленной версии и локальная рабочая копия **чистая**. После дополнительного подтверждения модуль возвращается к предыдущему SHA. Если пользователь уже редактировал файлы, откат блокируется: так изменения не потеряются.

## Защита локального API

Только `127.0.0.1` / localhost. Проверяются сокет, Host, Origin, JSON и специальный заголовок для POST. Контент GitHub не используется как произвольный адрес и не превращается в команду оболочки. Обновляющий процесс запускает `git` напрямую без оболочки.

## Ограничения безопасности

- Успешная GitHub CI — проверка тестов, **не доказательство отсутствия вредоносного кода**. Устанавливайте только доверенные коммиты.
- Изменения npm-зависимостей отдельно применяются через `npm install`, после перезапуска. Откат Git **не откатывает автоматически node_modules**.
- Для ZIP-копий, чужих origin или режима static preview установка отключена.
- Не используйте локальный updater для публичного сервера — это инструмент разработчика.
- Полноценная упаковка с атомарной заменой запущенного процесса, резервированием пакетов и офлайн-откатом — отдельный этап.
