# OMEGA v0.23 — unified cognitive infrastructure

One PR implements six integrated, bounded primitives:
1. NeuroFactory — verified-source hierarchical specialization through InfinityGrowth.
2. World Engine — shared-term relationship graph with source provenance (no inferred causality).
4. Cognitive Immune System — reject unconfirmed, malformed and same-source duplicate evidence.
5. Evolution Arena — holdout evaluation with zero accepted regressions.
6. Memory Tiers — deterministic working, episodic, semantic and archive labels, without deleting records.
8. Self-Engineering Lab — immutable proposals requiring human review; no code editing or self-merge.

The live GET /api/memory/omega/overview endpoint uses only Memory Core's consent-scoped visible evidence.
No external calls, autonomous source acquisition, real model training, secure remote federation,
production migration to physically separate storage tiers or independently measured intelligence increase.
All algorithms have CPU/memory bounds and the API is read-only.
