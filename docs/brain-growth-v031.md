# Мэйюрэн v0.31: саморазвитие мини-мозгов

Всё работает локально, без Cloud.ru и без отдельных программ. Новые шаги идут в режиме простоя после «смысла»: `growth`, затем `curiosity`.

## 1. Ветки по смыслу

`grow_branches` по-прежнему собирает ветки по общим словам. На первом уровне ветка дополнительно забирает факты своего мозга, близкие по смыслу к её центру (`semantic.MATCH`). Например, «эспрессо» попадает в ветку «кофе». Используются только векторы текущей версии факта и текущей модели. Если модель смысла выключена или ещё не скачана, ветки строятся только по словам.

## 2. Выжимка мини-мозга

`_compose` находит самую конкретную ветку (или свой мозг), чья тема названа в вопросе. Он добавляет строку «Выжимка мини-мозга «…»» с фактами, которые не попали в обычный поиск: до 420 символов, целыми утверждениями, со сроками. Факты проходят те же фильтры, что и поиск: облако, срок жизни, секреты.

## 3. Любопытство

`BrainGrowth.scan_questions` ищет пробелы двух видов:

- цель без срока: «К какому сроку хочешь это сделать?»;
- проект, о котором известен один факт: «Как продвигается проект …?».

Ответ чата получает поле `curiosity`, но только при всех условиях:

- переключатель `curiosity` включён;
- пользователь сам не задал вопрос;
- с прошлого вопроса прошло не меньше 6 часов.

Кнопка «Не спрашивать об этом» скрывает вопрос навсегда. Если факт забыть, вопрос удаляется вместе с ним. Если пробел закрыт (срок появился), вопрос исчезает при следующем простое. Ответ пользователя разбирается как обычная реплика, с теми же правилами приватности.

## 4. Бесконечный рост подключён

Шаг `growth` делает три вещи:

1. Пересобирает ветки.
2. Запускает `InfinityGrowth` на подтверждённых фактах (без секретов и личного): рост тем и один уровень специализации.
3. Пишет дневной снимок размеров мозгов (`memory_brain_history`, 60 дней).

Шаг подчиняется переключателю `auto_growth`.

## 5. Новые мозги — только с «да»

Тема-существительное, выросшая минимум в двух мозгах и набравшая 8 и более фактов, становится предложением (`memory_brain_proposals`). Одновременно висит не больше 3 предложений.

- «Да»: создаётся свой мозг (`memory_custom_brains`), который собирает факты по теме из всех мозгов и растит свои ветки. Факты остаются и в восьми основных мозгах.
- «Не надо»: тема больше не предлагается.
- «Убрать мозг»: факты не трогаются, и тема тоже больше не предлагается.

## 6. Карта мозгов

`GET /api/memory/brains/map` возвращает для каждого мозга:

- число фактов;
- рост за неделю (по снимкам);
- число веток и новые ветки;
- сильные ветки (средняя сила ≥ 0.6);
- засыпающие ветки (< 0.12).

В настройках памяти это панель «Карта мозгов» с предложениями новых мозгов.

## API

- `GET /api/memory/brains/map`
- `POST /api/memory/brains/proposals/{id}` с телом `{ "accept": true|false }`
- `DELETE /api/memory/brains/custom/{id}`
- `POST /api/memory/curiosity/{id}/dismiss`
- политика: `curiosity` (по умолчанию включено)
