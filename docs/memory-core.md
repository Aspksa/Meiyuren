# Meiyuren v0.7 — единый Memory Core

Все функции памяти размещены в одном Python-модуле: backend/app/memory_engine.py. Существующий FastAPI и SQLite остаются без дополнительных серверов, Redis, Ollama и автоматических платных Cloud.ru-вызовов.

## Жизненный цикл
- prepare(query, conversation_id, cloud_mode) перед ответом находит релевантную подтверждённую память через SQLite FTS5, ограничивает контекст 1700 символами и применяет разрешения.
- observe(exchange, conversation_id) после успешно сохранённого обмена создаёт идемпотентные задачи.
- Один локальный worker обрабатывает задачи, пока работает Meiyuren. После сбоя зависшие задания восстанавливаются из SQLite по lease. Извлечение работает по ограниченным регулярным выражениям; сложные фразы могут не распознаваться.
- Кандидаты на память требуют явного подтверждения. Сводки создаются как локальные дословные выписки из фраз пользователя и тоже требуют подтверждения.
- forget удаляет факт, FTS-запись, историю его ревизий и помечает соответствующие сводки непригодными. Удаление истории беседы очищает связанные кандидаты и память.

## Разрешения
- allow_cloud_notes / allow_cloud_facts по умолчанию false.
- Для передачи каждого факта необходимо отдельное cloudAllowed=true.
- Даже когда память не разрешена к отправке, при включённом Cloud.ru сам текст сообщения и недавняя история диалога передаются провайдеру. Это отдельное поведение Cloud-чата.
- Скрининг секретов эвристический и не гарантирует выявления всех персональных данных. Пароли, ключи и иные секреты не следует сохранять.
- Удаление из локального хранилища не отзывает ранее отправленные провайдеру данные, не удаляет резервные копии и не очищает исходные сообщения истории автоматически. Для последних предусмотрено отдельное управление.

## Миграция
При первом переходе к Memory Core создаётся консистентная резервная копия SQLite в файле с суффиксом .before-memory-core.bak. Ручные факты старого формата переносятся с kind=legacy без выдуманных источников, таблица прежних фактов очищается, а исходные диалоги и общая заметка остаются.
Делайте отдельную резервную копию каталога data/ перед обновлением. Git-откат не откатывает схему SQLite.

## Ограничения
- SQLite FTS5 применяет Unicode-токенизацию и префиксный поиск; это не семантический поиск и не полноценная русская морфология.
- Автоматические локальные кандидаты ограничены фразами вроде «запомни, что» и простыми предпочтениями. AI не создаёт непроверенных утверждений.
- Выписки не являются AI-пересказом: они содержат дословные фрагменты из диалогов. Обновление выписки снова требует подтверждения.
- История изменения факта доступна до его удаления. Tombstone по отпечатку помогает не извлекать уже удалённый факт.
- Новый модуль не выполняет платные запросы Cloud.ru, поэтому по умолчанию не вводится дополнительный бюджет для фонового AI.

## Обновление в Windows CMD
Остановите приложение, сохраните data/, затем запустите в каталоге репозитория: git pull origin main, npm ci, setup-python.cmd. Для запуска используйте Meiyuren.cmd. PowerShell не нужен.
