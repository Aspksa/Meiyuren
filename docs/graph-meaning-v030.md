# v0.30: граф людей и проектов, модель смысла

Этапы 3 и 5 плана https://claude.ai/artifact/HbFmnxGrEYEx2RFtuLUDu4. Без Ollama и без отдельных программ.

## Граф сущностей

- `understanding.entities(text)` находит только явно названное: людей («мой брат Петя», «Петя (брат)», имена по словарю pymorphy3), проекты («проект Kitsune»), места после предлога («в Казани»), организации («в Яндексе») и инструменты на латинице (Rust, FastAPI). Ничего не угадывает о неназванных людях.
- Таблицы `memory_entities`, `memory_entity_mentions`, `memory_entity_indexed`. Синхронизация идёт после каждой обработки очереди (`sync_entities`). «Забыть», очистка диалога и слияние в режиме простоя убирают связи сразу; сущность без фактов удаляется.
- Поиск: если вопрос называет человека, проект, место или роль («про Петю», «у моего брата»), все факты о нём получают бонус, даже без общих слов.
- API: `GET /api/memory/entities`, `GET /api/memory/entities/{id}` (факты и связанные сущности). В разделе памяти появился блок «Люди и проекты».

## Модель смысла

- `semantic.py`: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` через fastembed (ONNX, около 220 МБ, русский поддерживается). Тексты пользователя никуда не отправляются.
- Модель скачивается один раз в режиме простоя, в фоновом потоке, в `data/models`. При следующих запусках уже скачанная модель поднимается в фоне без сети. Переключатель «Модель смысла» в разрешениях памяти (`semantic_model`, включён по умолчанию) отключает и скачивание, и использование.
- Режим простоя (шаг `meaning`) считает векторы фактов в `memory_semantic_vectors`; «Забыть» удаляет вектор сразу.
- Поиск: сходство ≥ 0.55 с вопросом добавляет факт даже без общих слов («кофе» → «эспрессо»). Порог подобран по опыту и требует проверки на настоящей модели.
- Без fastembed или без скачанной модели всё работает как раньше.

## Тесты

`backend/tests/test_graph_meaning_v030.py`: извлечение сущностей, сбор фактов о человеке, вопрос по имени и по роли, мгновенное забывание, синонимы через модель (в тестах подменённая модель, без скачивания), переключатель. `conftest.py` запрещает тестам скачивать модель.

## Ограничения

- Модель в этой сборке не проверена на настоящих весах: из среды разработки HuggingFace недоступен. Порог 0.55 нужно сверить на реальных фразах.
- Имена ищутся по словарю: редкие имена и прозвища могут не распознаться. «Питер» без предлога распознаётся как имя.
