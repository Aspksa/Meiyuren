# Переносимый запуск Meiyuren

## Windows: запуск двойным щелчком

1. Установите Node.js 20 или новее с npm (если ещё не установлен).
2. Откройте папку проекта и дважды нажмите `Meiyuren.cmd`.
3. Запускатор проверит наличие зависимостей и при необходимости выполнит `npm install`.
4. Node.js проверит, свободен ли порт 5173. Если занят, выберет следующий свободный в диапазоне **5173–5272**.
5. Откроется браузер по **фактическому адресу** выбранного порта; окно запуска держите открытым.

Для установки ярлыка на рабочий стол один раз запустите **`Создать ярлык.cmd`**. Будет создан `Meiyuren.lnk` с собственным значком. После перемещения проекта на другой диск создайте ярлык заново, чтобы обновить путь.

## Флешка, внешний SSD, другой диск

Все пути определяются **от папки `Meiyuren.cmd`**, а не от `C:\` или конкретной буквы диска. Папку проекта можно переносить целиком на любые локальные или внешние носители в Windows.

**Важно:** это переносимость папки проекта, а не полностью автономный `.exe`. Для запуска на другом компьютере должны быть доступны:
- Node.js 20+ в PATH **или** совместимый Windows `node.exe` в `runtime/node.exe`;
- установленные зависимости в `node_modules` **или** npm + интернет для их установки.

Чтобы запускать без интернета, заранее выполните установку зависимостей под Windows нужной архитектуры, перенесите `node_modules` и, если требуется, `runtime/node.exe` вместе с проектом. После переноса лучше проверить запуск с этого носителя.

При работе в папке OneDrive или на медленной флешке установка зависимостей и первый запуск могут быть медленнее.

## Обычная командная строка Windows (cmd.exe)

```cmd
npm install
npm run dev
```

`npm run dev` также ищет свободный порт и открывает браузер. Для отключения автоматического открытия и использования стандартного Vite можно вызвать `npm run dev:vite`.

## Проверка

```cmd
npm run test:launcher
npm run typecheck
npm test
npm run build
```

## Безопасность

Сервер по умолчанию слушает только `127.0.0.1` и не доступен другим устройствам сети. Контент веб-приложения открывается через локальный браузер, а не как настольное приложение ОС. PowerShell не используется.
