# Интеграция Python и SQLite

Основная точка входа — `backend.app.main:app` (FastAPI). Локальная установка `setup-python.cmd` на Windows, виртуальное окружение `backend/.venv`.

База данных по умолчанию: `data/meiyuren.sqlite3`. Для тестов и изолированного запуска переопределяется переменной окружения `MEIYUREN_DATA_DIR`.

### Защита

FastAPI слушает `127.0.0.1` с TrustedHostMiddleware. Внешний CORS не включён. Сообщение не длиннее 2000 символов, память не длиннее 4000 символов, история ограничена 500 записями на запрос. Все SQL-запросы параметризованы. История и заметки не отправляются в интернет.

**Нет аутентификации:** не выставляйте порт Python в сеть. Локальные процессы пользователя имеют доступ к базе. Перед публикацией приложения нужно добавить полноценную авторизацию и CSRF/Origin-проверки.

### Данные / резервное копирование

Папка `data/` игнорируется Git и не затрагивается обновлением проекта. Закройте сервер и сделайте резервную копию `data`, прежде чем переустанавливать систему. Обновление/откат исходников не откатывает базу.

### Тестирование

```cmd
python -m pip install -r backend\requirements-dev.txt
python -m pytest backend\tests -q
```

Ответы в `backend/app/replies.py` сейчас демонстрационные. Для подключения AI реализуйте безопасный серверный адаптер, не сохраняйте токены на клиенте.
