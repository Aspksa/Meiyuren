# Мэйюрэн v0.32: логический мозг

Модуль `backend/app/reasoning.py` делает выводы из подтверждённых фактов. Работает по правилам, локально, без нейросети и без Cloud.ru. Выводы строятся в режиме простоя, на шаге `logic` (после `growth` и до `curiosity`).

## Главное правило

Вывод — это не факт пользователя.

- Выводы хранятся отдельно: `memory_inferences` и `memory_inference_premises`.
- В контексте чата у вывода есть префикс «Вывод из фактов (не сказано пользователем…)».
- У каждого вывода есть основания. Если забыть или изменить любой из исходных фактов, вывод удаляется сразу, даже если он был отклонён: он цитирует этот факт.
- 👎 («неверно») отклоняет вывод. Отклонённый вывод больше не появится.
- В облако вывод уходит, только если туда можно передать все его основания.

## Правила

1. **Цепочки.** Пример: «Мой брат Петя учится на юриста» + «Мой брат живёт в Казани» дают вывод ««Мой брат живёт в Казани» — это про Петю (брат)». Если людей с одной ролью двое, мозг не угадывает.
2. **Время.** Срок сегодня, завтра или через N дней (до 7). Если срок прошёл, мозг спрашивает: «Это уже сделано?».
3. **Противоречия.** Утверждение с отрицанием и утверждение без него с тем же смысловым ядром, например «Я не люблю кофе» и «Я люблю кофе». Мозг спрашивает: «Что верно сейчас?».
4. **Причина и следствие.** Привычка, проект или решение помогает цели, если у них общее ключевое слово или они близки по модели смысла.
5. **Правила-обобщения.** Три и больше фактов с одним и тем же временем («по субботам», «утром») дают правило с общими темами. Правило пересчитывается на новых фактах.

Вопросы о противоречиях и прошедших сроках попадают в «любопытство» (v0.31): не чаще раза в 6 часов, и только если переключатель включён.

## Где видно

- Под ответом чата, в «Память»: «Вывод: … · потому что «A» + «B»» и кнопка 👎.
- В настройках памяти, на панели «Логика»: все выводы по видам, с основаниями.

## API

- `GET /api/memory/inferences`
- `POST /api/memory/inferences/{id}/reject`
