# Архитектура Meiyuren

## MVP

Одностраничное приложение React + TypeScript + Vite.

- `Avatar`: глобальный плавающий слой. Левая кнопка без перемещения открывает чат. Перетаскивание начинается после порога в 7 px. Правая кнопка открывает настройки, системное меню подавляется только для аватара.
- `ChatPanel`: независимая панель чата с локальными демо-ответами. Никаких внешних запросов и API-ключей.
- `SettingsPanel`: панель размера, прозрачности, приветствия, сброса позиции и очистки чата.
- `useAppStore`: Zustand. Сохраняются только настройки и координаты в `localStorage`; история чата в этой версии не сохраняется.
- `lib/position.ts`: независимая и тестируемая математика границ окна.
- `services/replies.ts`: интерфейс-заготовка для будущего AI-провайдера; заменяем без изменения интерфейса чата.

## События

| Действие | Результат |
| --- | --- |
| ЛКМ без смещения | Открытие чата |
| Перетаскивание ЛКМ | Перемещение аватара в пределах окна |
| ПКМ по аватару | Собственные настройки |
| Enter / Space при фокусе на аватаре | Открытие чата |
| Shift+F10 при фокусе на аватаре | Настройки |

## Технологии

- React 18, TypeScript 5, Vite 5
- Zustand с persist
- CSS без тяжёлых UI-библиотек
- Vitest для логики и GitHub Actions для проверок

## Расширение

При подключении AI используйте серверный API/прокси: **не помещайте секретный API-ключ во фронтенд**. Для озвучки и эмоций выделите новые `features/voice` и `features/emotions`.

## Ограничения

Аватар перемещается только внутри вкладки приложения, не по рабочему столу ОС. Ответы — демонстрационные, без подключения модели. Настройки локальны для конкретного браузера.
