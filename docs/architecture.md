# Архитектура Meiyuren

## MVP

Одностраничное приложение React + TypeScript + Vite.

- `Avatar`: глобальный плавающий слой. Левая кнопка без перемещения открывает чат. Перетаскивание начинается после порога в 7 px. Правая кнопка открывает настройки, системное меню подавляется только для аватара.
- `ChatPanel`: независимая панель чата с локальными демо-ответами. Никаких внешних запросов и API-ключей.
- `SettingsPanel`: панель размера, прозрачности, приветствия, сброса позиции и очистки чата.
- `useAppStore`: Zustand. Сохраняются только настройки и координаты в `localStorage`; история чата в этой версии не сохраняется. При загрузке данные проверяются (`sanitizePersisted`): испорченные значения заменяются значениями по умолчанию.
- `lib/position.ts`: независимая и тестируемая математика границ окна.
- `services/replies.ts`: интерфейс-заготовка для будущего AI-провайдера; заменяем без изменения интерфейса чата.

## События

| Действие | Результат |
| --- | --- |
| ЛКМ без смещения | Открытие чата |
| Перетаскивание ЛКМ | Перемещение аватара в пределах окна |
| ПКМ по аватару | Собственные настройки |
| Enter / Space при фокусе на аватаре | Открытие чата |
| Shift+F10 при фокусе на аватаре | Настройки |
| Escape | Закрыть настройки, затем чат |

## Технологии

- React 18, TypeScript 5, Vite 5
- Zustand с persist
- CSS без тяжёлых UI-библиотек
- Vitest для логики и GitHub Actions для проверок

## Расширение

При подключении AI используйте серверный API/прокси: **не помещайте секретный API-ключ во фронтенд**. Для озвучки и эмоций выделите новые `features/voice` и `features/emotions`.

## Ограничения

Аватар перемещается только внутри вкладки приложения, не по рабочему столу ОС. Ответы — демонстрационные, без подключения модели. Настройки локальны для конкретного браузера.

## Векторная боковая панель и обновления

- `components/IconSidebar.tsx`: компактное меню из SVG-значков без видимых подписей; `aria-label` и `title` сохранены ради доступности.
- `public/assets/icons/update.svg`: оригинальная векторная иконка обновлений (два золотых оборота вокруг звезды).
- `components/UpdatePanel.tsx`: проверка, подтверждение установки, подтверждение отката, отображение CI и коммитов.
- `scripts/vite-updates.mjs`: локальные маршруты в Vite, защищённые проверкой loopback IP, Host, Origin и пользовательским подтверждением.
- `scripts/updater-service.mjs`: фиксированный источник GitHub, CI-гейт, fast-forward-only обновление и откат для чистой Git-копии.

Ограничение: это механизм синхронизации **исходного кода** для запущенного локально разработческого проекта, не полностью автономный обновляющийся бинарный пакет. Нужны Git и доступ к GitHub.


## Python + FastAPI + SQLite (v0.4)

- `backend/app/main.py`: FastAPI-эндпоинты, валидация входных данных, только loopback.
- `backend/app/db.py`: SQLite (`messages`, `profile_memory`) с транзакциями, параметризованными запросами и WAL.
- `backend/app/replies.py`: заменяемый движок демонстрационных ответов без сторонней модели.
- `src/services/chatApi.ts`: клиент HTTP, обработка ошибок.
- `src/components/MemoryEditor.tsx`: явные заметки памяти и очистка истории.
- `scripts/start.mjs`: совместный запуск Python-сервера и Vite с динамическими портами.

Данные хранятся в `data/meiyuren.sqlite3` (не в репозитории). Автоматическая миграция существующих настроек localStorage не затрагивается. В этой версии память — только заметка, которую пользователь ввёл сам; AI пока не подключён.
