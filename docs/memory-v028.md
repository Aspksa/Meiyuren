# v0.28: режим простоя

Когда пользователь молчит 10 минут, Мэйюрэн сама обслуживает память. Запуск не чаще раза в 30 минут, всё локально: ни Cloud.ru, ни платных вызовов. Любой POST в `/api/chat/*` ставит работу на паузу между шагами.

| Шаг | Что делает |
|---|---|
| 1. Консолидация («сон») | Сливает автоматические почти-дубли в одном мозге (одинаковый канонический текст или Jaccard ключевых слов ≥ 0.85). Старая запись становится `superseded` с ревизией `merged_while_idle`. Ручные факты не трогает. Противоречия «люблю / не люблю» попадают в отчёт как вопрос. |
| 2. Сила фактов | `memory_strength`: использование и 👍 укрепляют, 👎 ослабляет, без использования сила падает вдвое за 45 дней. В `deep_recall` сила слегка поднимает или опускает уже подходящий факт; слабые факты не удаляются. |
| 3. Самообучение поиска | `engine.evolve(force=True)`: на оценках пользователя (≥ 6), иначе на прокси-бенчмарке. |
| 4. Незаконченное | Активные проекты и цели (без личных данных) для карточки «Пока тебя не было». |
| 5. Локальные векторы | `memory_local_vectors`: триграммы основ ключевых слов. Если точных общих слов нет, сходство ≥ 0.4 даёт нечёткое совпадение («программирование» → «Я работаю программистом»). Синонимы с разными корнями не связывает. |
| 6. Здоровье | `PRAGMA quick_check` и ежедневный снимок в `data/backups` (хранятся 3). «Забыть» и очистка диалога удаляют снимки, чтобы забытое не вернулось из копии. |

API: `GET /api/idle/status`, `GET /api/idle/briefing`, `POST /api/idle/run` (запуск сразу), `POST /api/idle/seen`.

Таблицы `idle_runs`, `memory_strength`, `memory_local_vectors` создаются в `MemoryEngine.initialize`: создание таблиц на лету ломало параллельные запросы к FTS5.
