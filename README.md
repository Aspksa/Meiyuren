# Meiyuren 🦊

Интерактивный веб-аватар с обновлённым дизайном. **ЛКМ — чат, ПКМ — настройки, зажатая ЛКМ — перетаскивание.**

## Запуск двойным щелчком на Windows

**`Meiyuren.cmd`** запускает сайт, автоматически ищет свободный порт начиная с 5173 и открывает браузер.

**`Создать ярлык.cmd`** создаёт на рабочем столе ярлык **Meiyuren** с собственным значком. После переноса папки на другой диск запустите создание ярлыка ещё раз.

Подробности о запуске с флешки, внешнего SSD и других носителей: [docs/portable-launch.md](docs/portable-launch.md).

## Запуск из терминала Windows CMD или Bash

```bash
git clone https://github.com/Aspksa/Meiyuren.git
cd Meiyuren
npm install
npm run dev
```

Для запуска требуется Node.js **20+**. В Windows при двойном щелчке также поддерживается `runtime/node.exe` рядом с проектом (если уже установлены зависимости).

## Команды

```bash
npm run dev             # свободный порт + открыть браузер
npm run dev:vite        # стандартный Vite
npm run typecheck
npm test
npm run test:launcher
npm run build
```

## Управление

- **Левый клик по аватару:** чат.
- **Перетаскивание:** перемещение персонажа внутри вкладки.
- **Правый клик:** настройки персонажа.
- **Enter / Пробел:** открыть чат с клавиатуры; **Shift+F10:** открыть настройки.
- **Escape:** закрыть настройки, а затем чат.

Размер, прозрачность, позиция и приветствие сохраняются в браузере. Ответы в чате пока демонстрационные, без AI API.

Образ аватара выбирается в настройках (ПКМ → «Образ»). Картинки поз: `public/assets/avatar/poses/` (полная картинка `<id>.webp` и миниатюра `<id>-thumb.webp`), список поз — `src/lib/avatars.ts`. Иконка ярлыка и браузера: `public/assets/icons/meiyuren.ico`.

Архитектура: [docs/architecture.md](docs/architecture.md). Документация на русском языке. PowerShell не используется.

## Панель обновлений (v0.3)

На левой панели отображаются **только векторные иконки без текстовых подписей**: главная, чат, проверка обновлений, настройки и GitHub. Подсказка появляется при наведении, кнопки доступны с клавиатуры.

Нажмите на значок циклических стрелок для проверки последней версии `main` в [Aspksa/Meiyuren](https://github.com/Aspksa/Meiyuren). Установка:
- разрешается **только** для клона Git (`git clone`), на ветке `main`, без локальных изменений;
- доступна **только после успешной GitHub Actions CI** для точного коммита;
- требует отдельного подтверждения;
- выполняется через `git fetch` и `git merge --ff-only` без перезаписи локальных изменений;
- сохраняет точный коммит для отката, который также требует подтверждения и чистой рабочей копии.

После установки или отката перезапустите `Meiyuren.cmd`. Если обновились npm-зависимости, выполните `npm install`.

**ZIP-архивы, сайт на хостинге и режим `npm run preview` не могут самостоятельно менять файлы на компьютере.** Для работы установщика используйте `npm run dev` или `Meiyuren.cmd` в клонированной папке.

Подробности и ограничения: [docs/updates.md](docs/updates.md).
