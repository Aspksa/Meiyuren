# Meiyuren 🦊

Интерактивный веб-аватар: **левый клик — чат, правый клик — настройки, перетаскивание — перемещение**.

## Стек

React 18 · TypeScript · Vite · Zustand · Vitest.

## Быстрый старт (Bash, без PowerShell)

```bash
git clone https://github.com/Aspksa/Meiyuren.git
cd Meiyuren
npm install
npm run dev
```

Перейдите по адресу, который покажет Vite (обычно http://localhost:5173).

## Команды

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

## Управление

- **Левый клик по аватару** открывает чат.
- **Левая кнопка + движение** перетаскивает аватар.
- **Правый клик** открывает параметры аватара.
- **Enter / Пробел** на выделенном аватаре открывает чат; **Shift+F10** — настройки.
- **Escape** закрывает настройки, а затем чат.

Позиция, размер, прозрачность и приветствие сохраняются в браузере. В чате пока работают **локальные демонстрационные ответы** (без подключения AI).

Используемый аватар: `public/assets/avatar/meiyuren.webp`. Для замены сохраните новое изображение с тем же именем.

Подробности см. [docs/architecture.md](docs/architecture.md).
