# Meiyuren v0.5 — Cloud.ru, локальный чат и память

Веб-аватар Meiyuren (React + TypeScript + Vite), левое SVG-меню, обновления GitHub и локальный сервер Python/FastAPI.

## Первый запуск на Windows (только CMD, без PowerShell)

После обновления Git-копии проекта:

```cmd
git pull origin main
npm ci
```

Дважды нажмите `setup-python.cmd`: скрипт создаст `backend/.venv` и установит FastAPI/Uvicorn (нужен Python 3.11+ и интернет для первой установки). Затем двойной щелчок по `Meiyuren.cmd` — Node найдёт свободные порты для сайта и Python, запустит оба сервера и откроет браузер.

Команды для обычной CMD вместо двойного щелчка:

```cmd
setup-python.cmd
npm run dev
```

На Linux/macOS:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci
npm run dev
```

При переносе папки на другой компьютер или носитель Python-окружение `backend/.venv` иногда нужно пересоздать. База `data/meiyuren.sqlite3` не включена в Git и остаётся с проектом.

## Чат

- История сообщений сохраняется в SQLite и отображается после перезапуска.
- Отправка сообщения записывает пару «вопрос/ответ» одной транзакцией.
- Окно показывает загрузку истории, состояние ответа и ошибки соединения.
- Очистка истории доступна из настроек после подтверждения.

## Память

В настройках → «Память Мэйюрэн» можно вручную записать и сохранить заметку (не более 4000 символов). Она остаётся в SQLite, даже если приложение закрыто. Для проверки отправьте в чат «Что ты помнишь?».

**По умолчанию:** демонстрационный локальный бот. Для настоящей облачной модели настройте Cloud.ru в боковом меню (значок облака).

## API

- `GET /api/health` — статус Python.
- `GET /api/chat/messages?limit=200` — последние сообщения.
- `POST /api/chat/messages` — сообщение и ответ.
- `DELETE /api/chat/messages` — удаление истории.
- `GET /api/memory` — чтение заметки.
- `PUT /api/memory` — сохранение заметки.

Python слушает только `127.0.0.1`, порт 8000–8099. Веб-адрес — свободный порт 5173–5272. Vite направляет запросы чата на фактический порт Python.

## Правила

PowerShell не используется. В демо-режиме история и заметки локальные. При включённом Cloud.ru часть истории, текущий запрос и заметка отправляются облачному провайдеру. Не публикуйте локальные API наружу без авторизации. Отдельно сохраняйте резервную копию каталога `data`: Git-откат кода не откатывает пользовательскую базу.

## Cloud.ru Foundation Models (v0.5)

В левом меню появилась новая **векторная иконка облака без подписи** (подсказка при наведении). После клика откроется окно настроек Cloud.ru.

1. Создайте сервисный API-ключ в [консоли Cloud.ru](https://cloud.ru/docs/foundation-models/ug/topics/quickstart) для сервиса Foundation Models.
2. Введите **Key Secret** в поле с маскировкой и нажмите **Сохранить ключ**.
3. Нажмите **Получить список** — сервер проверит подключение через `GET /v1/models`.
4. Выберите текстовую модель и нажмите **Применить модель**. С этого момента чат использует `POST /v1/chat/completions`.
5. Кнопка **Выключить Cloud.ru** возвращает демонстрационный локальный режим. **Удалить** удаляет ключ из системного хранилища.

**Ключ не хранится в браузере, SQLite, Git или файлах конфигурации.** Backend использует библиотеку `keyring` и системное хранилище секретов, например Windows Credential Manager. На ОС без доступного безопасного хранилища сохранение будет запрещено. Секрет никогда не возвращается в ответы API.

Выбранная модель и переключатель облачного режима хранятся в SQLite (`cloud_settings`). Cloud.ru получает **текущий текст, до 12 сообщений истории и содержимое заметки памяти** только при включённом облачном режиме. Запросы могут быть платными, интернет обязателен. Статус ключа доступен без раскрытия его значения.

При обновлении проекта запустите `setup-python.cmd`, чтобы установить новые зависимости Python (`httpx` и `keyring`). Окружение нельзя без проверки переносить между Windows-компьютерами. Повторный вход ключа может потребоваться после переноса на другой ноутбук.

Подробная инструкция: [docs/cloud-ru.md](docs/cloud-ru.md).
