# Meiyuren v0.4 — локальный чат и память

Веб-аватар Meiyuren (React + TypeScript + Vite), левое SVG-меню, обновления GitHub и локальный сервер Python/FastAPI.

## Первый запуск на Windows (только CMD, без PowerShell)

После обновления Git-копии проекта:

```cmd
git pull origin main
npm ci
```

Дважды нажмите `setup-python.cmd`: скрипт создаст `backend/.venv` и установит FastAPI/Uvicorn (нужен Python 3.11+ и интернет для первой установки). Затем двойной щелчок по `Meiyuren.cmd` — Node найдёт свободные порты для сайта и Python, запустит оба сервера и откроет браузер.

Команды для обычной CMD вместо двойного щелчка:

```cmd
setup-python.cmd
npm run dev
```

На Linux/macOS:

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
npm ci
npm run dev
```

При переносе папки на другой компьютер или носитель Python-окружение `backend/.venv` иногда нужно пересоздать. База `data/meiyuren.sqlite3` не включена в Git и остаётся с проектом.

## Чат

- История сообщений сохраняется в SQLite и отображается после перезапуска.
- Отправка сообщения записывает пару «вопрос/ответ» одной транзакцией.
- Окно показывает загрузку истории, состояние ответа и ошибки соединения.
- Очистка истории доступна из настроек после подтверждения.

## Память

В настройках → «Память Мэйюрэн» можно вручную записать и сохранить заметку (не более 4000 символов). Она остаётся в SQLite, даже если приложение закрыто. Для проверки отправьте в чат «Что ты помнишь?».

**Важно:** это пока демонстрационный локальный бот, а не подключённая AI-модель. Автоматического анализа личных данных и внешних AI-запросов нет.

## API

- `GET /api/health` — статус Python.
- `GET /api/chat/messages?limit=200` — последние сообщения.
- `POST /api/chat/messages` — сообщение и ответ.
- `DELETE /api/chat/messages` — удаление истории.
- `GET /api/memory` — чтение заметки.
- `PUT /api/memory` — сохранение заметки.

Python слушает только `127.0.0.1`, порт 8000–8099. Веб-адрес — свободный порт 5173–5272. Vite направляет запросы чата на фактический порт Python.

## Проверки

```cmd
npm run typecheck
npm test
npm run test:launcher
npm run test:backend
npm run build
```

Тесты Python также запускаются в GitHub Actions на Windows и Linux.

## Правила

PowerShell не используется. История и заметки — локальные, не отправляются во внешние AI-сервисы. Не публикуйте локальные API наружу без авторизации. Отдельно сохраняйте резервную копию каталога `data`: Git-откат кода не откатывает пользовательскую базу.
